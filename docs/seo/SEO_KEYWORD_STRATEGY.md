## 🎨 On-Page SEO Template

For each new landing page, use this structure:

### Meta Tags:
```html
<title>[Keyword] | Layouts360 - [Unique Value Prop]</title>
<meta name="description" content="[Keyword] for Indian developers. [Key benefit]. [Social proof]. [CTA]. Starting at ₹2,000/month.">
<meta name="keywords" content="[primary keyword], [2-3 related keywords], plot management, real estate software India">
<link rel="canonical" href="https://layouts360.com/[page-url]">
```

### H1 Structure:
```
H1: [Keyword]: [Emotional Hook/Benefit]
  H2: What is [Keyword]?
  H2: Why [Target Audience] Needs [Keyword]
  H2: Key Features
    H3: Feature 1
    H3: Feature 2
    H3: Feature 3
  H2: [Keyword] vs. [Alternative]

  H2: FAQs
```
