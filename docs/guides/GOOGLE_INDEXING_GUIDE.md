## 🔍 How to Check If Pages Are Indexed

### Method 1: Google Search Console
1. Go to GSC → Coverage
2. Look for "Valid" pages count to increase
3. Check "Indexed" tab to see your new URLs

### Method 2: Google Search
Search for: `site:layouts360.com "asset management"`

If indexed, you'll see the page in results.

1. **Coverage** → Check "Indexed" count

3. **Enhancements** → Check for any errors

## 🚨 Troubleshooting

### If Pages Don't Index After 2 Weeks:

**Check 1: Crawl Errors**
- GSC → Coverage → Errors
- Fix any 404s or server errors

**Check 2: Robots.txt**
- Make sure pages aren't blocked
- Check: `https://layouts360.com/robots.txt`

**Check 3: Sitemap**
- Verify sitemap includes new pages
- Check: `https://layouts360.com/sitemap.xml`

**Check 4: Request Again**
- Sometimes Google needs a second nudge
- Request indexing again after 2 weeks
